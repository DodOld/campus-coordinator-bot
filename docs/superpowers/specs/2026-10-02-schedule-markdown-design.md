# Markdown-публикация расписания

## Цель

Показывать расписание 0B62 в Telegram так же компактно, как в примере
пользователя: единым моноширинным блоком с сохранёнными переносами строк.

## Решение

- Go-парсер остаётся источником обычного текста; он не зависит от Telegram.
- Python-слой доставки формирует MarkdownV2 fenced code block для заголовка и
  тела расписания.
- Текст из внешнего источника экранируется так, чтобы обратные кавычки не могли
  завершить fenced block или изменить разметку.
- Если текст превышает лимит Telegram, он делится по строкам на независимые,
  корректно закрытые кодовые блоки.
- Обычные Debug-сообщения и сообщения VK не меняются.

## Проверка

Тесты должны подтверждать экранирование обратных кавычек, валидные границы
каждой части длинного расписания и передачу `MarkdownV2` в `send_message`.
README описывает моноширинный Markdown-формат.
