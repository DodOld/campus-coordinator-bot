# VK-команды для участников Debug-темы

## Цель

Разрешить любому участнику настроенной Telegram-группы управлять VK-источниками
из служебной темы Debug.

## Решение

- Удалить из обработчика `!vk` проверку статуса администратора и вызов
  `getChatMember` для этой цели.
- Сохранить проверки разрешённого `chat_id` и `message_thread_id` темы Debug.
- Сохранить ограничение целей VK только настроенными темами Posts или Schedule,
  а также существующие проверки аргументов, дедупликацию и санитарные ошибки.
- Обновить справку, README и тесты, чтобы они не обещали ограничение для
  администраторов.

## Проверка

Тесты подтверждают, что команда в Debug не требует объект Bot или статуса
администратора, а команды вне Debug по-прежнему игнорируются.
