# Форматирование справки в Debug

## Цель

Отобразить заранее заданную справку `!help` с Telegram HTML-разметкой, не меняя права доступа к VK-командам и не интерпретируя другие Debug-сообщения как HTML.

## Решение

- Обработчик `!help` передаёт `parse_mode=HTML` только в своём вызове `send_debug`.
- Текст справки остаётся статической константой приложения.
- Права сохраняются: `!help` доступна всем в Debug, а `!vk` по-прежнему требуют администратора.
- Тест проверяет, что HTML-режим передан в Telegram API именно при отправке справки.
